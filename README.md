# kcillam.github.io

This repository only holds `robots.txt`. GitHub Pages serves it at
https://kcillam.github.io/robots.txt, the one address crawlers check — including for
the website at https://kcillam.github.io/website/ (source: `kcillam/website`).

`.nojekyll` makes GitHub serve the files as they are, so there is no page at
https://kcillam.github.io/ itself.
